# BagBin — Корзина 1.12.0

WoW WotLK 3.3.5a / Interface30300 / Lua5.1.
Окно: /bagbin, /bbin или значок сумки у миникарты.

В1.12.0 мастер-лут, автогрид и подтверждение ручного уничтожения удалены из
интерфейса и обработчиков BagBin. Управление ими находится в UnBot: /ubloot.
В BagBin нет отдельной выдачи предметов, бросков или обхода ручного вопроса.
Прежние сохранённые значения и списки получателей оставлены для миграции в UnBot.
WTF внешне не редактируется. После обновления достаточно /reload.

Пять вкладок: «К удалению», «Неполные», «Белый шмот», «Исключения», «Белые спис.».

Корзина уничтожает предметы, это не продажа и не дополнительное хранилище.
Удалённое вернуть нельзя. По умолчанию подходит только серый хлам с известной
положительной ценой: цена единицы × полный размер стака строго меньше порога.
Порог задаётся целыми полями золота/серебра/меди, начальное значение10с.
Задания, камни возвращения6948/44314, личные исключения, неизвестные,
непродаваемые и заблокированные вещи защищены. Зелёные и выше не удаляются.
Конкретный белый предмет можно разрешить через «Белые спис.»; порог сохраняется.
«Исключения» полностью защищают добавленные предметы от очистки BagBin.
Предмет задаётся ID или Shift+кликом ссылки в поле. Действия подтверждаются в чате.

«Неполные» показывает серый хлам, текущая пачка которого дешевле порога,
а полный стак не дешевле. Таймер1–60минут (default3) отсчитывается без изменения
количества; затем предмет попадает в общую очередь по текущей цене.
Перемещение, изменение количества и /reload начинают отсчёт заново.
«Белый шмот» — только ручное удаление белого оружия/брони по выбранному слоту.
Автоматическая очистка эту вкладку не использует.

Резерв свободных обычных мест0–100 (default5): автоочистка удаляет самые дешёвые
подходящие стаки до восстановления резерва. Ручная очистка не зависит от резерва.
Автоочистка включена по умолчанию и запускается после закрытия лута, вне боя.
При просмотре окна, смерти, занятом курсоре, торговле, банке, почте и открытом
луте удаление не начинается. Каждый слот перепроверяется, один раз за проход;
шаг не чаще0.25с, проход до60с, проверка удаления до2с. При неподтверждённом
удалении автоматика останавливается до /reload без повторного спама.

Разрешение автоочистки в подземелье сохраняется на24часа отдельно для персонажа
и данжа: оба ответа переживают reload/выход/вход. До ответа удаление блокируется;
ручные вкладки доступны. Эта защита автоочистки сохранена; она не относится
к перенесённой вкладке подтверждения ручного уничтожения.

При <=1 свободном обычном месте предлагается доступный торговец и сумма продажи
серого хлама/непривязанной зелёнки, с защитой заданий и исключений.
Дживс49040, хламобот40769, роботы110G34113/74A18232 проверяются по предметам,
инженерии, доступности и откату; расходуемые варианты подписаны.
Изученные тундровые мамонты61425/61447 предлагаются снаружи на суше; разрешение
конкретной зоны определяет сервер. Вызов только по ручной secure-кнопке вне боя,
без повторов. Продажа ручная. Автоудаление ждёт предложения и120с после запроса.
«Не сейчас» не повторяется до восстановления мест и нового заполнения.

Команды:
- /bagbin vendor — сумма продажи и доступный торговец;
- /bagbin clean — очистить сейчас;
- /bagbin on или off — автоочистка;
- /bagbin threshold 10 — порог в серебре;
- /bagbin keep ID / unkeep ID — добавить/снять личное исключение;
- /bagbin extra ID / unextra ID — разрешить/убрать конкретный белый предмет.

Настройки и исключения сохраняются отдельно для персонажа. Реестры UnBot,
пресеты, история и личные базы не очищаются. ZIP этой версии не собирался.

Проверка: /reload, /bagbin — только пять вкладок, прежний порог/исключения.
Для ручного безопасного теста защитить один серый предмет и очистить другой:
чат «Корзина: Освобождено мест: N. Цена удалённого: ...»; защищённый остаётся.
Мастер-лут/автогрид/ручное уничтожение настраиваются только в /ubloot.
При сбое — полный скриншот и время. Lua-модель не заменяет игровой тест.
