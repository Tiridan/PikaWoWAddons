# DungeonSeeker 1.1.6 — конкретное подземелье и цель

Аддон для WoW WotLK 3.3.5a (Interface 30300, Lua 5.1), рассчитанный на короткий
заход в выбранное подземелье: войти, собрать руду/добычу и выйти.

## Использование

После установки полностью перезапустите WoW; после обновления достаточно /reload.
На экране находятся две кнопки:

- «Войти» — запускает очередь именно выбранного подземелья;
- «Выйти» — выходит из подземелья, затем покидает группу и остаточную очередь.

Средняя кнопка мыши по любой из двух кнопок открывает меню выбора. В меню можно
найти подземелье по названию и выбрать его. Названия и доступность берутся из
клиентского каталога LFG; недоступные цели помечаются. Поиск запускается вне
группы, очереди, подземелья, боя и смерти.

После штатного приглашения Blizzard нажмите «В подземелье». Автоматический
AcceptProposal не используется. Поддерживается соло-состояние сервера
abandonedInDungeon; аддон не добавляет ботов и не вызывает LeaveParty. После
входа аддон прекращает поиск, чтобы игрок мог спокойно фармить входную точку. Когда закончите,
нажмите «Выйти»: аддон использует тот же LFGTeleport(true), что и зелёная
кнопка «Перенестись из подземелья», дождётся выхода и выполнит очистку группы
не более одного раза. Все действия ограничены таймаутом.

После LFG-входа справа появляется небольшая панель «Цель»: она показывает
финального босса для подземелий Classic, Запределья и Нордскола. Когда журнал боя сообщает
о его смерти, строка меняется на «Цель выполнена», а в чат приходит одно такое же
сообщение. В 3.3.5 нет API живого списка LFG-боссов, поэтому это не пытается
угадать состояние каждого промежуточного босса. Панель можно перетащить левой
кнопкой мыши; её положение сохраняется в `DungeonSeekerDB.objectivePoint`.

Перед подтверждением приглашения и после загрузки проверяется фактическое
подземелье. Если сервер вернул другой LFG ID или другое известное название,
аддон останавливает поиск и не принимает чужой заход.

SavedVariablesPerCharacter `DungeonSeekerDB` сохраняет `targetID`, `roles` и
старые неизвестные поля без очистки. Старое поле `randomID` может остаться в
файле, но больше не используется.

## Команды и короткий тест

`/ds` — открыть меню; `/ds enter` или `/ds start` — войти;
`/ds exit` или `/ds stop` — выйти/отменить поиск; `/ds status` — диагностика.

Игровой тест:

1. Выполнить `/reload`.
2. Средней кнопкой по «Войти» открыть меню и выбрать «Крепость Утгард».
3. Нажать «Войти» и подтвердить штатное приглашение «В подземелье».
4. После загрузки убедиться, что панель показывает «Нужно убить: Ингвар Расхититель».
5. Убить Ингвара и убедиться, что строка меняется на «Цель выполнена».

Ожидаются строки «Ищем конкретно: Крепость Утгард», «Нажмите «В подземелье»...»,
«Цель поиска выполнена: Ингвар Расхититель» и после выхода «Вы вышли из подземелья».

UnBot и BossMemory, а также их SavedVariables, этим изменением не затрагиваются.
