# Solo Progress Guide 0.8.31

## Обновление 0.8.31

Этап 3 переименован в «Врата Ан’Киража и Зул’Гуруб». Нажатие этапа или
«Мой путь» на нём открывает общий обзор: отдельный независимый допуск
Зул’Гуруба и два альтернативных пути Ан’Киража — Скипетр (А) и Молот (Б).
Все три входа находятся в начале раздела. Верхняя кнопка Зул’Гуруба убрана.
У каждой цепочки есть возврат к общему обзору этапа 3. Просмотр другой ветки
и Зул’Гуруба не меняет сохранённый выбор; подтверждение пути осталось явным.
Задания и сохранённые ключи шагов не менялись. Требуется `/reload`.


## Обновление 0.8.30

Исправлен общий разбор GetAchievementInfo: признак выполнения берётся из
четвёртого результата API WoW 3.3.5, а не из третьего (число очков).
Неполученные достижения больше не закрывают боссов, руны Рагнароса и не дают
ложный ориентир по истории. Сообщение о новом достижении требует живого
подтверждения API; старая сохранённая отметка для него не используется.
История и ручные отметки сохраняются. Автозачёт Classic Наксрамаса по
свежему ответу сервера работает отдельно. Требуется `/reload`.


## Обновление 0.8.29

Счётчик Classic Наксрамаса в списке этапов теперь считает три видимых пункта:
допуск, четыре квартала и финал рейда. Один сданный вариант допуска считается
одним выполненным пунктом; после серверного подтверждения прохождения получается
3/3. Каталог заданий допуска остаётся отдельной историей трёх альтернатив.
Нужен `/reload`, затем запрос «Мой этап» для свежего подтверждения пунктов 2 и 3.


## Обновление 0.8.28

На Solo Progress пункты 2 и 3 классического Наксрамаса закрываются автоматически
после свежего ответа «Мой этап» со значением 7–18. Подписи прямо указывают
серверную прогрессию как основание; отдельные убийства кварталов не выдумываются.
Сохранённый ответ после входа или `/reload`, ручной выбор и история достижений
не дают автозачёт. После нового ответа ниже 7 автозачёт снимается; личные
ручные отметки сохраняются. Реалм Solo и остальные пункты не затронуты.
Нужен `/reload`, затем один запрос «Мой этап».

## Обновление 0.8.6

Повторяемая «Рука праведника» больше не считается полностью завершённой после
первой сдачи. Репутационный участок показан как четыре партии по 200 панцирей:
одна сдача «Пути праведника» и три повторные сдачи «Руки праведника», всего

Новые сдачи автоматически учитываются по изменению репутации после окна сдачи

квеста, поэтому старый прогресс восстанавливается как минимум `1 / 3`; для
коррекции прошлых сдач на карточке добавлены кнопки `−1` и `+1 сдача`.
Появление «Анахроноса» или Нейтралитет с Родом Ноздорму также завершает этот
участок. Нужен `/reload`.

## Уже играющий персонаж

Откройте «Мой этап» и нажмите «Запросить мой этап»: вне боя аддон сам выделит текущего персонажа целью. Поддерживается исходный формат `Progression Level for ИМЯ = N`. Другой формат отображается для ручной сверки; произвольные числа не принимаются за фазу. Ответ о боте не меняет ваш профиль. История заданий загружается автоматически и обновляется кнопкой. Более поздняя фаза не создаёт выдуманную историю необязательных квестов. Старые достижения — подсказка о прошлом, а не доказательство текущей фазы после `.ip low`.

Настройки сохраняются в SoloProgressGuideDB, ключ профиля — реалм и GUID персонажа. Неизвестные поля сохраняются. SavedVariables физически записываются при `/reload` либо нормальном выходе.

## Границы версии

Количество ресурсов с `~` — базовая справка Questie/Classic. Взятое задание с числовой целью в журнале заменяет её фактическим количеством. Учитываются только предметы при себе; обычный банк и Ling не засчитываются. Наличие предметов не означает сдачу.

Серверные правила и ошибки Колоссов, сокращённая репутация Скипетра, особые идентификаторы заданий и локализованный формат .ip могут различаться. Их нельзя считать подтверждёнными исходным кодом модуля. Ветка Скипетра включена как последовательность заданий; зависимости от предметов/NPC и полная интерактивная схема из Attune пока не перенесены. Не все режимы старых убийств можно восстановить по достижениям: окончательный доступ сверяется по фазе.

Аддон не посылает команды ботам, не кликает квесты и гонг, не меняет фазу персонажа, не запускает рейды. .ip get отправляется только кнопкой пользователя, вне боя, при безопасной цели. Запросы истории ограничены по частоте и имеют таймаут.

Сохранённый текст используют копирование и обе кнопки чата. «Исходный текст» восстанавливает заготовку после сохранения. Изменения хранятся для персонажа; при изменении исходной заготовки новая версия не подменяется устаревшей правкой.

## Версия 0.3.6

«Скопировать» в готовом сообщении со ссылкой выдаёт только URL, без номера части и названия задания. Без ссылки копируется текст. Вставка в чат использует полное сообщение.

## Версия 0.3.7

Ответ про гонг самодостаточен: ресурсные задания, печати, полное название Скипетра и место удара. Отсылки «в спойлере» удалены из сообщений для чата. Раскрытый обход добавляет конкретный вариант с Молотом Зул’Фаррака и предупреждение о потере наград.

## Версия 0.3.8

Рядом с вики в помощи доступен список Wowhead по распознанным именам и заданиям. Раскрытие спойлера добавляет его ссылки. Каждая ссылка копируется отдельно; неподтверждённые страницы обозначены как поиск. Для Квиаги, обоих молотов и Скипетра заданы прямые страницы Classic.

## Версия 0.3.9

В списке Wowhead URL виден сразу под названием, справа — «Копировать».
Кнопка выделяет URL в этой же строке; нажмите Ctrl+C. Второе окно не открывается.
Клиент 3.3.5 не предоставляет аддонам прямую запись в системный буфер.
После обновления выполните /reload. Проверка: откройте ссылки подсказки,
нажмите «Копировать», Ctrl+C и вставьте в браузер — должен вставиться только URL.
Сообщений в чат при этой операции нет.

## Версия 0.4.0

В источниках подсказки появилась «На карту» для доступных координат. Выбор цели включает метку карты/миникарты и стрелку TomTom старого API. Встроенный каталог берёт координаты персонажей и начала/сдачи заданий из установленного Questie-335, с разделением Classic/Wotlk. Внутренние координаты подземелий и неподдержанные зоны не используются. Для Рексара рисуется классический патруль по трём зонам через QuestieMap:DrawManualIcon/DrawWaypoints, отдельно от пользовательских значков. TomTom ведёт к месту поиска. «Убрать метки» снимает только наши метки и линии. Требуется перезапуск клиента для нового файла Navigation.lua и OptionalDeps.

## Версия 0.6.2

Первый пункт после Огненных Недр заменён на «Получить допуск в Логово Крыла Тьмы»: задание 7761 с автоматическим статусом истории и прохождением вместо технического пояснения и ручной отметки. ## Версия 0.6.0

Убраны готовые сообщения, кнопки вставки в обычный/мировой чат и редактор сообщений. Старые пользовательские черновики в SavedVariables не удаляются, но интерфейс их больше не использует. Поиск остаётся справочником прохождений без чат-панели.

На «Моём пути» внутри пунктов есть «Прохождение»: редакционные инструкции по материалам описаний и комментариев Wowhead, серверные уточнения и ссылки. Одиночное задание показано сразу после раскрытия; длинные цепочки доступны здесь же, с раскрытием отдельных заданий. Рядом с персонажами, предметами и объектами есть Wowhead и, при известных координатах, «На карту». Бот-обходы остаются отдельными спойлерами. Это перенос существующих материалов по 155 заданиям, а не полная копия всех комментариев сайта.

Игровая проверка: /reload → «Мой путь» → этап 2 → «Прохождение» у входа в Логово Крыла Тьмы. Должны появиться шаги «Приказа Чернорука» без окна чата. В цепочках Рексара «На карту» открывает зону и патруль; ожидаемое сообщение — «Маршрут патруля показан линиями Questie на карте.».

## Версия 0.5.0

Для всех 155 заданий текущих цепочек добавлены авторские пошаговые инструкции по описаниям и полезным комментариям Wowhead. Рейтинг голосов через доступное представление страниц не проверяется: тексты не обозначены как самые популярные комментарии. Источники зафиксированы в research/solo-progress/quest-comment-sources.json. Учтены отличия Solo Progress для Рексара, урны, Олума и гонга.

Страница задания сначала показывает URL Wowhead, затем шаги, серверные уточнения и отдельные строки сущностей. Адрес выделяется прямо в строке для Ctrl+C. «На карту» доступна для известных наружных координат персонажа/объекта или источника предмета. Единственная точка ставится сразу; при нескольких предлагается выбор. Служебные невидимые NPC не показываются. Новая таблица QuestHelp.lua не меняет SavedVariables. Нужен полный перезапуск клиента для нового файла.
