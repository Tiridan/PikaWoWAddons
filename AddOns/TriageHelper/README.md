# Triage Helper 1.0.1

Начиная с ProfessionPath 1.1.0 помощник встроен в «Путь ремесленника». Если оба
аддона включены, эта отдельная копия автоматически остаётся неактивной, чтобы не
показывать вторую панель и повторные номера. Без ProfessionPath она продолжает
работать самостоятельно.

Маленький помощник для заданий 6622/6624 «Очередь на медобслуживание» в WoW WotLK 3.3.5a.

После принятия задания аддон:

- показывает крупные номера над дружественными табличками пациентов;
- ставит смертельно раненых выше тяжелораненых, а тех — выше обычных раненых;
- среди пациентов одной тяжести ставит раньше того, чья табличка появилась раньше;
- даёт защищённую кнопку использования очередного перевязочного бинта на текущую цель.

## Как пройти

1. Примите задание.
2. Нажмите `Shift+V`, чтобы включить дружественные таблички, или нажмите кнопку в окне аддона.
3. Выберите пациента с меткой `1 / СЕЙЧАС`.
4. Используйте кнопку `Перевязать цель` или положите квестовый бинт на горячую клавишу.
5. Пока идёт перевязка, заранее выберите следующую цель.

## Команды

- `/triage` — скрыть/показать окно;
- `/triage show` и `/triage hide` — явно показать/скрыть;
- `/triage debug` — вывести в чат текст всех видимых табличек для диагностики.

Аддон не выбирает цель и не использует предмет без клика игрока.
